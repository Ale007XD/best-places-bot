# Best Places Bot

Telegram-бот: топ-3 кафе, ресторана и бара рядом с пользователем.

**Диалог:** геопозиция → один экран параметров (радиус + минимальный рейтинг +
«Искать») → одно сообщение с тремя местами. Под каждым: 🗺 карта · 📤 поделиться · 👍/👎 «был здесь».
Язык определяется автоматически (по языку Telegram), параметры запоминаются.

Стек: Python 3.11, aiogram 3.x, httpx, Redis, pydantic-settings, Docker Compose.

---

## Быстрый запуск

```bash
cp .env.example .env      # заполнить BOT_TOKEN и FSQ_API_KEY — больше ничего не нужно
docker compose up -d --build
docker compose logs -f telegram-bot
```

Обязательные переменные — только `BOT_TOKEN` и `FSQ_API_KEY` (Service Key из
Foursquare Developer Console). Остальное опционально, см. `.env.example`.

Проверка ключа Foursquare одной командой:

```bash
curl -s "https://places-api.foursquare.com/places/search?ll=10.7769,106.7009&radius=500&limit=1&fsq_category_ids=63be6904847c3692a84b9bb5" \
  -H "Authorization: Bearer $FSQ_API_KEY" -H "X-Places-Api-Version: 2025-06-17"
```

Команды бота: `/start`, `/me`, `/buy`, `/language`, `/paysupport`, `/terms`.
Админ (`ADMIN_ID`): `/money` (включить/выключить монетизацию, лимиты), `/stats`, `/feedback`, `/refund <charge_id>`.

### Поиск

1. Кэш в Redis (10 мин) хранит **сырой** список мест по точке/радиусу/языку —
   без рейтинга в ключе, поэтому смена порога рейтинга не тратит API-вызовов.
2. Один запрос к Foursquare на все категории (restaurant / coffee shop / bar).
   Если поля `rating`/`stats` недоступны по ключу (4xx), запрос автоматически
   повторяется с базовыми полями; тогда бот показывает ближайшие места с пометкой.
3. Mapbox/VietMap вызываются **только** если Foursquare вернул пусто и заданы ключи.
4. Дедупликация (нормализованное имя + расстояние ≤ 75 м) → фильтр по радиусу →
   фильтр по рейтингу → ранжирование (0.7·рейтинг/5 + 0.3·близость).
   Если мест с нужным рейтингом меньше трёх, добираются лучшие из остальных
   (с пометкой), а не пустой ответ.

### Хранение данных

Геопозиция и параметры лежат в FSM (Redis) не дольше 6 часов; в `user_prefs:{id}`
сохраняются только радиус и порог рейтинга; координаты не пишутся никуда, кроме FSM.

## Монетизация и геймификация

**По умолчанию монетизация ВЫКЛЮЧЕНА** — после обновления никто не упрётся в paywall.
Админ управляет на лету командой `/money` (настройки в Redis, переживают перезапуск):
`/money` — статус, `/money on` / `/money off`, `/money free N` (бесплатных поисков в день),
`/money exempt off` — отключить безлимит админа, чтобы проверить paywall на себе.
Пока выключено: лимитов и paywall нет, `/buy` отвечает «сейчас бесплатно»; серия, рефералы и
отметки продолжают копиться.

**Лимит.** Бесплатно `FREE_SEARCHES_PER_DAY` поисков в день (+1 за каждый день серии,
максимум `STREAK_BONUS_CAP`). Списывается только успешный поиск, который не взят из кэша:
ответы из кэша, пустые результаты и ошибки бесплатны. Бонусные поиски тратятся после
дневного лимита. Новый день наступает по `QUOTA_UTC_OFFSET_HOURS`.

**Paywall** (когда монетизация включена) показывается только когда лимит исчерпан (после нажатия «Искать»), никогда
до первого поиска. Товары за Telegram Stars (XTR): +20 поисков, Pro на 7/30 дней
(потолок `PRO_DAILY_LIMIT`), заморозка серии. Цены — `STARS_PRICE_*`.

**Серия.** День засчитывается за успешный поиск. Награды за 3/7/14/30 дней — бонусные
поиски. Заморозка спасает серию при одном пропущенном дне.

**Рефералы.** Ссылка `t.me/<bot>?start=ref_<id>` (в `/me` и на paywall). Оба получают
`REFERRAL_BONUS` поисков после ПЕРВОГО успешного поиска приглашённого. Уже искавшие
пользователи и самоприглашение не засчитываются; потолок `REFERRAL_MAX_REWARDED`.

**Платежи.** `pre_checkout_query` проверяет цену и владельца заказа, повторная доставка
`successful_payment` идемпотентна (`payment:{charge_id}`). Возврат: `/refund <charge_id>`
(админ); выданный товар автоматически не отзывается.

Метрики: `/stats` показывает покупки, Stars за день и показы paywall.

## Произвольная точка поиска

Искать можно не только «рядом со мной». Где задать точку: 📎 → «Геопозиция» → выбрать любое
место на карте; или написать адрес/название места; или прислать координаты / ссылку Google Maps
(в т.ч. короткую `maps.app.goo.gl`); или переслать место (venue). Кнопка «🗺 Другая точка» на
экране параметров подсказывает варианты, «📍 Рядом со мной» возвращает назад.
«Домашняя» геопозиция при выборе временной точки не перезаписывается; в выдаче и на экране
параметров видно, где идёт поиск. Адреса ищутся через OpenStreetMap Nominatim (текст запроса
уходит на их сервер; `GEOCODER_ENABLED=false` отключает). Полноценный выбор точки внутри
Telegram-интерфейса без «скрепки» возможен только через Mini App — отдельный этап.

## Отметки «был здесь»

👍/👎 под карточкой. Один голос на пользователя и место (можно передумать). Для мест без
рейтинга провайдера считается «народный» рейтинг со сглаживанием: `5·(👍+1)/(👍+👎+2)`,
в выдаче он помечен 🥷. Чтобы дотянуть место до порога «4.0+», нужно не меньше трёх
одобрительных отметок подряд. Награда: каждые `VOTE_REWARD_EVERY` новых отметок — +1 бонусный
поиск (не больше `VOTE_REWARD_DAILY_CAP` в день).

## Ссылки «на карту» и «поделиться»

Ссылка на карту ищет заведение по названию и адресу и центрируется на его координатах. Раньше
ссылка строилась по голым координатам, и Google показывал только их. Place ID Google у нас нет
(данные Foursquare/OSM), синхронизация с Google Places для этого не нужна. 📤 открывает выбор
получателя с названием, адресом, ссылкой на карту и реферальной ссылкой на бота.

## Метрики качества

`/stats` (админ) показывает: долю поисков с тремя местами, без рейтинга, с «добором», из кэша,
число обращений к API (прокси стоимости), сбои Foursquare, использование OSM-фолбэка, число
случаев «недоступно» и среднее время ответа. Одинаковые параллельные запросы с промахом кэша
объединяются (один вызов API).

## Известные ограничения

- Категории Foursquare: новый API принимает только 24-символьные ID (числовые вроде 13065 дают HTTP 400). Используется родитель «Dining and Drinking»; если и он отвергнут — запрос без фильтра и отбор по названию категории.
- Эндпоинт VietMap не подтверждён документацией — это аварийный фолбэк.
- `rating`/`stats` — расширенные поля Foursquare; их доступность зависит от тарифа ключа.
